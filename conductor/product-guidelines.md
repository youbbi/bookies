# Product Guidelines: Bookies

## Language

**Primary language: French**
The app will be developed with French as the primary language. All UI copy, notifications, and messaging will be in French first. Future internationalization may be considered.

## Tone & Voice

### Warm yet Concise

- Conversational and friendly, like chatting with a friend about books
- Brief and functional—never verbose or in the way
- Casual language that feels personal without being overly cute

### Examples

- Welcome message: "Bon retour!" (not "Bienvenue dans votre bibliothèque personnelle!")
- Empty shelf: "Rien ici pour l'instant." (not a long explanation)
- Borrow request: "Marie aimerait emprunter ce livre"

## Visual Identity

### Color Palette

- **Warm and cozy**: Creams, soft browns, warm wood tones
- **Background**: Light cream/beige for readability
- **Accents**: Warm browns, muted greens, soft amber
- Avoid harsh whites or cold grays

### Book Display

- **Real book covers are the star**: Display actual cover images prominently
- Use high-quality cover art from book APIs
- Cards with subtle shadows and rounded corners
- Clear status badges (Disponible, Emprunté par...)

### Shelf Metaphor

- Visual bookshelf elements to create warmth (wood textures)
- Subtle illustrated touches (plant, lamp) for personality
- Grounded in realism—books look like real books, not abstract shapes

### Typography

- Clean, readable sans-serif for UI
- Warm serif for headings where appropriate
- Generous line height for comfortable reading

## Interaction Patterns

### Tap-Focused Clarity

- All core actions use explicit buttons and taps
- No hidden gestures required for essential functions
- Clear visual feedback on all interactions
- Predictable, consistent behavior throughout

### Minimal Onboarding

- Skip straight to the main interface
- Subtle contextual hints rather than tutorials
- Let users explore naturally
- First action should be adding a book, not reading instructions

## Accessibility

### Readability First

- High contrast text that meets WCAG AA standards
- Book covers include alt text descriptions
- Warm color palette adjusted to maintain accessibility
- Clear tap targets (minimum 44pt)
- Legible font sizes throughout

## UI Reference Patterns

### Book Cards

- Large cover image as primary element
- Status badge overlay (top-right corner)
- Owner/borrower info when relevant
- Subtle shadow for depth

### Friend Circles

- Avatar initials in warm, muted circles
- Friend count and activity indicators
- Horizontal scrollable lists for browsing

### Navigation

- Bottom tab bar for core sections (Ma Bibliothèque, Amis, Découvrir)
- Simple, icon-forward navigation
- Current section clearly highlighted
